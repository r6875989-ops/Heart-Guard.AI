# ❤️ HeartGuard AI

> **An AI-powered heart disease prediction system built to explore practical Machine Learning, explainable AI, and healthcare-focused decision support.**

HeartGuard AI transforms a machine learning prediction model into a complete web application experience.

## 🧠 Core Idea

The system takes patient health-related inputs and produces an ML-based heart disease risk prediction, together with supporting recommendations and an easy-to-understand result.

### ML Workflow

```
Patient Data
    ↓
Data Preprocessing
    ↓
Feature Scaling
    ↓
Trained ML Model
    ↓
Risk Prediction
    ↓
Explainability + Recommendations
```

## ✨ Key Features

- 🫀 Heart disease risk prediction
- 🤖 Machine Learning model integration
- 📊 Probability-based prediction
- 🔎 SHAP-based model explainability
- 🥗 Personalized diet suggestions
- 🏃 Exercise recommendations
- 🚨 High-risk emergency flagging
- 📄 PDF prediction reports
- 👤 User registration and login
- 🗄️ Prediction history
- 📈 Admin analytics dashboard
- 📊 Interactive Chart.js visualizations

## 🧪 Explainable AI

A major focus of HeartGuard AI is making ML predictions easier to understand.

The project uses **SHAP (SHapley Additive exPlanations)** to examine feature contributions and provide insight into why a model produces a particular prediction.

This moves the project beyond:

> **"The model predicted X."**

toward:

> **"Which input features contributed to the prediction?"**

This project demonstrates an end-to-end ML application workflow:

**Data → Model → Inference → Explainability → Web Application → User Result**

It is intended as an educational and engineering project and **does not replace professional medical diagnosis or treatment**.
